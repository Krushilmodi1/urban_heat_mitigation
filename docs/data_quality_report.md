## 2. Data Cleaning & Quality Audit Findings

### 2.1 Missing Values Analysis
A complete sweep across all 3,322 rows and 25 columns of `spatial_grid_metrics.csv` identified:
* **Missing Values**:
  * `mean_footprint_m2`: 40 missing values (1.20% of records).
  * All other 24 columns (`grid_id`, `year`, `LST`, `NDVI`, `NDBI`, `building_density`, `x_utm`, `y_utm`, etc.): **0 missing values (100% complete)**.
* **Root Cause & Handling**:
  * The 40 missing values in `mean_footprint_m2` occur exclusively in rural/peri-urban edge cells where `building_count == 0`. Dividing total footprint by 0 yielded `NaN`.
  * **Remediation**: Imputed to `0.0 m²` in `models/pinn.py` and `models/train_pinn.py`, which is domain-accurate.

## 3. Machine Learning Preprocessing & Data Leakage Prevention

### 3.1 Spatial Block Partitioning (Anti-Leakage Architecture)
* **Problem**: Standard random splits cause severe spatial autocorrelation leakage (cells 1 km apart share near-identical microclimates and land use).
* **Solution**: Implemented **Contiguous 8 km $\times$ 8 km Spatial Block Holdout**:
  * Entire 8 km blocks are held out together.
  * Train samples: 2,542 rows (76.5%).
  * Test samples: 780 rows (23.5%).
  * Both 2024 and 2025 observations for any grid cell remain in the same block split, eliminating coordinate leakage.

### 3.2 Feature Normalization
* Scalers (`StandardScaler` and min-max feature scalers) are **strictly fit on training blocks only** (`X_train`), and transformed onto test blocks (`X_test`) to prevent distribution leakage.
